# AUVE | e-commerce
<h3>📖 Description:</h3>

- A modern, fully responsive e-commerce platform that offers a seamless end-to-end shopping experience. Users can create a secure account via the signup and login system to explore dynamic products showcased on the contemporary homepage. The platform allows customers to select items, customize their choices based on real-time size and quantity availability, and manage them within an optimized persistent shopping cart. Checkouts are processed securely through Stripe, supporting multi-method payments such as Credit Cards, Apple Pay, and Google Pay. Once a purchase is completed, users can track their transactions and monitor the live fulfillment status directly within their dedicated Orders section.

- Secure Authentication 
- Project management (CRUD: Create, Read, Update, Delete)

- Inventory-Driven Cart
- Advanced Checkout Flow
- Order Tracking System
- Fully Responsive Design

<h3>⚙️ Installation:</h3>

To run this project locally, you can follow these steps:

1. Clone the repository:
```bash
git clone https://github.com/prayer-on/AUVE---ecommerce.git
```

2. Select the Backend folder:
```bash
cd Backend
```

3. Install the dependencies:
```bash
npm install
```

4. Start the server:
```bash
npm run dev
```

5. Select the Frontend:
```bash
cd Frontend
```

6. Install the dependencies:
```bash
npm install
```

7. Start the Frontend:
```bash
npm run dev
```
